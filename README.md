# quant-agents · 多智能体量化研究框架

用一组**职责分离的 Agent** 做量化研究，并且**只承认样本外结果**。

这个仓库不是"炒股策略"，而是一套**方法论实验台**：它把"模型到底有没有预测能力"
这个问题，拆成多个互相制衡的 Agent，再用滚动验证、最终留出集、统计检验去逼问它。

> **重要结论先说**：本项目验证下来，**日频股价方向预测没有可靠预测能力**（见下文方向 A / D）；
> 而**波动率预测是可用的**（方向 C，5 指数 × 3 周期共 15 个组合中 14 个优于朴素基准）。
> 所以这个仓库真正的产出不是"选股建议"，而是一份**诚实的负面/正面结论清单**。

## 一、四个方向的结论一览

| 方向 | 任务 | 方法 | 结论 | 可信度 |
|---|---|---|---|---|
| **A** | 个股未来 5/10 日涨跌 | 119 只主板股 × 250 万行, 38 特征, 6 轮迭代 | 样本外命中率 52.3% vs 基线 50.4%, AUC 0.53, 折级胜率仅 3/7 | ✗ 微弱且不稳 |
| **D** | 沪深300 该不该持仓 | 21.7 年日线, 9 个 Agent, 漂移修正 + DM 检验 | skill=+0.0023 (p=0.38), 留出期年化 1.59% 输给满仓 2.04%, 跨指数不一致 | ✗ 无预测能力 |
| **C** | 未来 5/10/20 日波动率 | 40 个波动率特征, QLIKE + Diebold-Mariano | **14/15 组合优于朴素基准, 11 个 p<0.10**; 相对 HAR 古典基准 9/15 为正 | ✓ **有效** |
| **阀门** | 用波动率预测做仓位管理 | 波动率目标 + 方向门 | 开发期大幅改善(年化 −1.1%→+2.4%, 回撤 −64.6%→−34.1%), **留出期反而变差** | ✗ 未能外推 |

最关键的三个发现：

1. **A 股指数有天然上行漂移**，"闭眼满仓"的 10 日上涨概率就有 **53.6%**。
   任何择时模型必须超过这个数才有意义——而它没有。
2. **特征里能被读出的信息全在波动率维度**。方向 D 的特征重要性前 6 名是
   `dd_all / ma60_ma120 / vol120 / vol60 / atr_pct / dd250`，**没有一个方向类特征**。
   这个线索直接导致了方向 C 的成功。
3. **叠加层最容易骗自己**。波动率阀门在开发期（2008-2022）表现得非常好，
   一进留出期（2022-2026）就失效——这正是"最终留出集"存在的意义。

## 二、Agent 人设清单

### 方向 A：个股涨跌（`train_agents.py`，8 个）

| # | 人设 | 职责 |
|---|---|---|
| 1 | 数据官 | 建股票池、抓历史、数据体检 |
| 2 | 特征官 | 造 38 个特征，**只能用 ≤t 的信息** |
| 3 | 标注官 | 定义预测目标与基准率（t+1 开盘买、t+1+h 开盘卖） |
| 4 | 模型官 | 训练 + walk-forward 滚动样本外预测 |
| 5 | 评估官 | 命中率/AUC/分档单调性/策略收益/基线对比 |
| 6 | 质疑官 | 过拟合、泄露、稳定性审查，**打乱标签重训**做泄露检测 |
| 7 | 调度官 | 读质疑官结论，决定下一轮改什么 |
| 8 | 档案官 | 排行榜 + 跨会话记忆 |

### 方向 D：指数择时（`timing_agents.py`，9 个）

在 A 的基础上新增：

| # | 人设 | 职责 |
|---|---|---|
| 6' | **时机评估官** | 非重叠调仓回测 + **漂移修正指标 skill** + 二项检验 |
| 9 | **外检官** | 同一模型直接套到其他 4 个指数，检验信号普遍性 |

### 方向 C：波动率/风险（`vol_agents.py`，9 个）

| # | 人设 | 职责 |
|---|---|---|
| 5' | **波动评估官** | QLIKE 损失 + **Diebold-Mariano 检验** + 与 HAR-RV 古典基准对比 |
| 6'' | **阀门官** | 把波动率预测变成仓位（波动率目标 + 方向门） |

### 它们怎么"互相交流学习"

**改的是流程与配置，不是模型权重**（LLM 之间不会互相训练）：

1. **共享黑板** `Blackboard.store`——后者读前者的产物
2. **消息传递** `logs/*_handoff.log`——谁把什么交给了谁，可审计
3. **跨轮次记忆** `out/memory.jsonl`——调度官读质疑官结论 + 历史记忆，决定下一轮改哪个变量

## 三、方法论：九道"防自欺欺人"的关口

这是本仓库最值得复用的部分。

1. **只用 ≤t 的信息造特征**（防未来函数）
2. **t+1 开盘买入、t+1+h 开盘卖出**（不用收盘价成交，避免乐观偏差）
3. **Walk-forward 滚动验证**：每折只用该折之前的数据训练
4. **和"猜多数类"基线比较**，而不是只看准确率
5. **最终留出集**：最后 20% 交易日全程不参与任何特征/模型/轮次的选择，只测一次
6. **漂移修正指标**：`skill = 持仓信号期上涨概率 − 空仓信号期上涨概率`（方向 D 用）
7. **非重叠调仓**：保证观测独立，t 检验才成立
8. **Diebold-Mariano 检验**（波动率预测）+ **打乱标签重训**（泄露检测）
9. **跨标的/跨周期外检**：5 指数 × 3 周期矩阵，看结论是否普遍

以及一份**必须声明的偏差清单**（存活偏差、选择偏差、复权偏差、重叠持仓、冲击成本……），
由质疑官自动附在每份报告末尾。

## 五、怎么跑

环境：Windows + WSL2(Ubuntu 22.04) + conda 环境 `crisp`(Python 3.10)。

```bash
pip install pandas numpy scikit-learn scipy matplotlib requests baostock

cd /mnt/d/quant-agents

# 方向 C: 波动率预测(推荐先跑这个)
python -u vol_agents.py --rounds 5
python -u vol_robust.py            # 5 指数 × 3 周期 稳健性矩阵

# 方向 D: 指数择时
python -u timing_agents.py --rounds 6 --h 10

# 方向 A: 个股涨跌(需先缓存个股历史, 约 300 只)
python -u prefetch_bs_par.py 300 0 6 2015-01-01   # 分片下载, 0/6 可改成 1/6 ... 5/6
python -u train_agents.py --universe 300 --rounds 4 --cached-only
```

**数据源说明**：Python 的 `requests/urllib` 的 TLS 指纹会被东方财富/腾讯的 WAF 拒绝
（`RemoteDisconnected` / `curl rc=56`），所以本项目统一走 **curl 子进程**；
腾讯在连续几百次请求后会**整段封 IP**（跳转 `waf.tencent.com/501page.html`）；
最终方案是 **Baostock**（免费、无 token、不限流、指数历史回溯到 2005）。

## 六、四条后续实验的结论（2026-10-12 凌晨补）

| 建议 | 产出 | 结论 |
|---|---|---|
| 1 波动率仓位管理框架 | `vol_target.py` | ✅ **有效**：回撤稳定砍掉约 40%，单位风险收益不输满仓 |
| 2 横截面选股 + 波动率仓位合体 | `combo.py` | ⚠️ 波动率仓位有效；**选股无效（跑输全池等权）** |
| 3 补齐 HAR-RV 差距 | `vol_har.py` | ❌ **失败**：加半方差/跳跃/四次变差特征反而变差 |
| 4 扩池 257 → 700 只 | Baostock | ✅ 模型变强（AUC 0.521→0.539），但仍转化不成收益 |

### 最重要的一条：**命中率提升 ≠ 收益提升**

700 只池子、h=5 的横截面相对模型：

| | 命中率 vs 基线 | AUC | top10 平均 5 日收益 | 全池平均 |
|---|---|---|---|---|
| 开发期(2017-2024) | +2.30pp | 0.5331 | 0.421% | 0.205% |
| 留出期(2024-2026) | +2.78pp | 0.5387 | **0.764%** | **0.794%** |

留出期**命中率更高，但 top10 组合平均收益反而低于全池**。
原因：模型擅长识别“略高于中位数”的股票，而全池均值被少数大牛股拉高——
**模型能选出“不太差的”，选不出“最好的”。**

> ⚠️ **陷阱警告**：这类回测里最大的收益来源其实是“等权小市值”这个宽基效应。
> 留出期全池等权年化 44.3%、夏普 1.73，而沪深300 买入持有只有 10.7%。
> 如果只拿沪深300 当基准，会误以为选股模型很有用（19.5% vs 10.7%）。
> **真正的对手是“全池等权”。**

更多细节见 `out/后续四条建议_结果.md`。

## 七、自主训练框架（2026-10-12 新增）

前六节的结论都是人工一个一个实验得出来的。第七节把“试实验”本身也自动化了。

### `auto_train.py`：自主搜索

在一个时间预算内自动跑几十上百个配置，搜索目标就是**组合收益**，而不是命中率。

搜索维度（192 个配置）：

| 维度 | 取值 |
|---|---|
| 预测标签 | 全体中位数 / 同行业中位数 / 同(行业×波动率组)中位数 / 跑赢沪深300 |
| 预测周期 | h = 5 / 10 / 20 |
| 模型 | 梯度提升树 / 逻辑回归 / 深层梯度提升树 / 随机森林 |
| 特征集 | 全部 / **去大盘特征** / 仅动量 / 仅横截面排序 |
| 持仓数 K | 5 / 10 / 20（不重训，直接换回测） |
| 仓位模式 | 满仓 / 波动率目标 |

**每个配置都用 walk-forward 得到真样本外预测**，逐条追加到
`out/search_leaderboard.jsonl`（可断电续跑）。

### `auto_train2.py`：集合 + 精调 + 最终验收

1. 输出所有配置的**分布**——量化多重比较带来的选择偏差
2. 按 (标签, 周期) 分组做**概率集合**（同组内多个模型概率平均）
3. 围绕最优配置做**局部精调**（超参 × 训练样本上限）
4. **只在最后对开发期最优者在留出集上评估一次**
5. **逐年拆解**，看优势是否集中在少数几年

### 为什么“全池等权”是真基准

本框架里每个选股策略的对照物都是**同期同股票池的等权收益**，而不是沪深300。
理由见第六节：留出期全池等权年化 44.3%，而沪深300 只有 10.7%——
拿沪深300 当基准会把任何模型都显得很厉害。

## 八、建议②③的结果与实盘方案（2026-10-12 上午新增）

### 建议②：换掉目标函数 —— **有效，但不稳**

`tail_ltr.py` 用**多段滚动留出（4 段）**对比了不同目标函数（h=10）：

| 目标函数 | rank IC | 正比例 | 满仓组合超额 |
|---|---|---|---|
| 分类 - 是否进前 25% | −0.007 | 50% | −3.9% |
| 回归 - 截尾收益（绝对误差） | +0.067 | 65% | −13.0% |
| 回归 - 截尾收益（平方误差） | +0.046 | 63% | −7.3% |
| **回归 - 横截面排名** | **+0.085** | **72%** | **+7.15%** |
| **分类 - 跑赢中位数** | **+0.086** | **72%** | **+2.27%** |

- **换目标函数确实起作用**：从“是否高于分位”换成“预测横截面排名”，超额从负转正。
- 但逐段看：前 3 段 top10 都跑赢全池（+0.7~+1.0pp/10日），**第 4 段（2024-08~2026-09）反而跑输**。
- “预测截尾收益”的 rank IC 也不低，但组合大幅落后 —— 直接建模收益会被少数极端值带偏。

### 建议①：接受宽基等权为基准线 + 方差拖累量化

`plan_3000.py` 随机等权持有 K 只（30 次抽样平均，每 10 日调仓）：

| 持仓数 | 算术年化 | 复利年化 | 年化波动 | 复利代价 |
|---|---|---|---|---|
| 10 | 21.49% | 17.63% | 32.26% | 3.86% |
| 50 | 22.46% | 19.74% | 29.31% | 2.72% |
| 全池 | 21.90% | 19.27% | 28.69% | 2.63% |

> **集中持有有真实的复利代价**（10 只比全池多付约 1.2pp/年），但量级不大 ——
> 真正的问题不在这里，而在“模型抓不到右尾”。

### 实盘方案

`实盘方案_3000元.md`：把研究结论转成可执行清单 ——
**宽基 ETF 组合 + 波动率阀门（<15%→100%，15~22%→70%，>22%→40%）+ 月度再平衡带 + 严格成本控制**。
可选一个 ≤1000 元的“实验仓”用横截面排名模型选股，但**预期是≈市场减成本**，不是跑赢。
